# 💳 CSS Pricing Plans

A pricing plans design created using **pure HTML and CSS**, without JavaScript.

## ✨ Features

- Multiple pricing plan cards
- Custom CSS styling
- Clean and organized layout
- Hover effects
- Responsive design
- No JavaScript required

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Files

- `index.html` — Contains the HTML structure.
- `style.css` — Contains the CSS styling.

## 🎯 Purpose

This project is part of my frontend development journey, exploring how HTML and CSS can be used to create attractive and organized user interfaces.
